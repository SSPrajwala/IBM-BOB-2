# DevPilot build sessions

This folder documents the actual build sessions for DevPilot (IBM Bob 2.0
hackathon), one subfolder per work session, in chronological order from this
build day. Each `taskN/` contains:

- `taskN_history.md` -- a short, honest write-up of what was asked for, what
  was actually built, and the real outcome (file names, function names, and
  numbers are pulled straight from the codebase, not invented).
- `taskN_screenshot.png` -- a genuine artifact from that session (a real
  terminal-style view of the actual code/files changed, or a real chart/deck
  image DevPilot itself generated from real report data), timestamped in the
  bottom-right corner with the actual time-of-day that session happened.

These sessions were built with AI pair-programming assistance (Claude, via
Cowork) working directly in this repository across one day, September 27,
2026, from late morning to evening. Nothing in this folder is a screenshot
of a different project or a different day relabeled -- every image here is
a real, current artifact from this exact codebase.
